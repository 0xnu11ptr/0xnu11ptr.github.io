My Active Directory Enumeration Checklist

October 22, 2026 · 2 min read · #active-directory#enumeration#notes

Most Active Directory compromises are not about a fancy exploit. They are about one small mistake that enumeration shows you. This is the checklist I follow at the start of every internal test or lab, once I have a first set of domain credentials.

Use these techniques only on systems you are allowed to test.

1. Know the domain

# Domain controllers, domain name, SMB signing
nxc smb 10.10.10.0/24

# Password policy before any spraying
nxc smb DC01 -u user -p 'Password' --pass-pol

Check the lockout threshold before you try any password. Locking out half of the company is a bad first day.

2. Users, groups and descriptions

nxc ldap DC01 -u user -p 'Password' --users
nxc ldap DC01 -u user -p 'Password' --groups

Read the user descriptions. Admins still put passwords there.

3. Collect for BloodHound

bloodhound-python -d corp.local -u user -p 'Password' -ns 10.10.10.10 -c All

In BloodHound, start with Shortest Paths to Domain Admins from your owned user, then look at outbound object control: GenericAll, GenericWrite, WriteDacl, ForceChangePassword.

4. Roastable accounts

# Kerberoasting
GetUserSPNs.py corp.local/user:'Password' -dc-ip 10.10.10.10 -request

# AS-REP roasting
GetNPUsers.py corp.local/ -usersfile users.txt -dc-ip 10.10.10.10 -no-pass

5. Shares and files

nxc smb 10.10.10.0/24 -u user -p 'Password' --shares

Look for scripts, web.config, unattend.xml and backup files. Developers leave connection strings everywhere — I know, because I am one.

6. ADCS

certipy find -u user@corp.local -p 'Password' -dc-ip 10.10.10.10 -vulnerable

Misconfigured certificate templates are one of the fastest paths to Domain Admin today.

Remediation, always

  • Use long random passwords (or gMSA) for service accounts to stop Kerberoasting.
  • Enable Kerberos pre-authentication on every account.
  • Remove passwords from descriptions, shares and scripts.
  • Review ACLs on sensitive groups and audit ADCS templates.
  • Enforce SMB signing on all hosts.

Every finding in a report should come with a fix like these. That is what makes a test useful.
