Case 01 · The Dossier

The developer who learned to think like the attacker

I am a penetration tester with OSCP+ and HTB CPTS, and a background as a full-stack developer in C#/ASP.NET Core and React/TypeScript.

I focus on internal and external network tests, Active Directory compromise and web application assessments. Writing production code every day gives me an edge in source code review and in finding business logic flaws that scanners miss. I know how real teams ship software, so my findings come with practical fixes, not just a list of CVEs.

Case 02 · The Method

Every compromise is a mystery with only one truth

The same deduction on every engagement: follow the clues, connect them, name the culprit, close the case.

Clue 1

Recon

Ports, services, users, leaked files. Nothing is too small.

Clue 2

Foothold

One weak password, one bad upload, one injection is enough.

Clue 3

Escalation

From a low user to SYSTEM or root on the first host.

Clue 4

Pivot through the network and follow the trust between hosts.
